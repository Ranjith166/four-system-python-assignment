This is a starter reconstructed from the screenshots, NOT the original course repository. The assignment's exact APIs, fixtures, and expected test totals may differ. Review against the official rubric before submitting.

## Setup
Python 3.10+. Run `python -m pip install pytest`, then `python -m pytest tests/ -v`.

The four sample implementations are in `system1/` through `system4/`. Evidence folders are templates; regenerate them from your actual runs rather than treating these as official course evidence.
